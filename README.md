# Responsive Web Design – Future of Web

This is my first-semester final project for the Web Programming course at Satakunta University of Applied Sciences (SAMK).

## About the Project

I developed a responsive website using HTML and CSS to practice web page structure, styling, and layout design.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Features

- Multiple website sections
- Responsive layouts for different screen sizes
- Navigation and styled buttons
- Signup form interface (frontend design only)

## What I Learned

Through this project, I practiced building web pages, organizing HTML and CSS files, creating responsive layouts, and improving website design.

**Note:** This is a frontend learning project. The signup form does not include backend functionality.
